# Cloud Team Project

Учебный облачный проект по дисциплине **«Основы облачных технологий»**.
Вариант 4 - контейнерное приложение.

## О проекте

Небольшое веб-приложение на Flask, которое упаковано в Docker-контейнер. Проект нужен, чтобы потренироваться собирать образ, запускать контейнер и вести совместную работу в GitHub. Приложение отвечает на запрос простой строкой, этого хватает, чтобы проверить, что контейнер работает.

## Архитектура

Пользователь отправляет запрос на порт хоста, Docker перенаправляет его в контейнер, где работает Flask-приложение. Настройки приложение берет из переменных окружения.

```
Клиент (браузер / curl)
        |
        v
  localhost:8080 (хост)
        |
        v
 Docker-контейнер (порт 5000)
        |
        v
  Flask-приложение  <---  переменные окружения (config/.env)
```

| Компонент | Назначение | Связь с другими компонентами |
|-----------|------------|------------------------------|
| Клиент | Отправляет HTTP-запрос | Обращается к приложению через порт 8080 |
| Docker-контейнер | Изолированная среда с Python и зависимостями | Пробрасывает порт 8080 хоста на 5000 внутри |
| Веб-приложение (Flask) | Обрабатывает запросы и отдает ответ | Работает внутри контейнера, читает настройки |
| Конфигурация | Параметры запуска (порт, БД) без секретов | Передается в контейнер через `--env-file` |

## Структура репозитория

```
cloud-team-project/
├── app/
│   ├── app.py              # код приложения
│   └── requirements.txt    # зависимости Python
├── config/
│   ├── README.md
│   └── example.env         # пример конфигурации без секретов
├── docs/
│   ├── README.md
│   └── docker.md           # подробная инструкция по Docker
├── .gitignore
├── Dockerfile              # сборка образа
└── README.md
```

- `app/` - исходный код приложения
- `config/` - примеры конфигурации, настоящий `.env` в репозиторий не попадает
- `docs/` - документация
- `Dockerfile` - описание сборки Docker-образа

## Запуск

### Что нужно заранее

- установленный [Docker](https://docs.docker.com/get-docker/) (на Windows - Docker Desktop)
- Git

### Шаги

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/Nepreff/cloud-team-project.git
   cd cloud-team-project
   ```
2. Создать файл с настройками из примера и при необходимости поменять значения:
   ```bash
   cp config/example.env config/.env
   ```
3. Собрать образ:
   ```bash
   docker build -t cloud-team-app:v1 .
   ```
4. Запустить контейнер:
   ```bash
   docker run -d --name cloud-team-app -p 8080:5000 --env-file config/.env cloud-team-app:v1
   ```
5. Проверить, что все работает:
   ```bash
   docker ps
   curl http://localhost:8080
   ```
   Должна вывестись строка `Cloud team project is running!`

### Остановка

```bash
docker stop cloud-team-app
docker rm cloud-team-app
```

Подробнее про порты и переменные окружения - в [docs/docker.md](docs/docker.md).

> **Важно:** настоящие пароли и токены в репозиторий не добавляются. В `config/example.env` только шаблоны вида `<your_password>`.
